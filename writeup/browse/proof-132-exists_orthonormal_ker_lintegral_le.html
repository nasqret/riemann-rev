lemma exists_orthonormal_ker_lintegral_le

What it saysLet \mathfrak{s} be a shape, s \in \mathbb{N}, L real, m and \iota finite types and C a complex m \times \iota matrix with | \iota | = s + 1 + 3 ( \varrho + 1 ), 4 \le L (h4), rank C \le 3 ( \varrho + 1 ) and | \iota | \le L ( c ). Then there are a set D \subset \iota and a complex \iota \times D matrix O with CO = 0 and O^{H} O = 1 (orthonormal columns) such that for every j \in \mathbb{N}: \int_{u \in \mathbb{C}^{\iota} : | u_{i} | \le L^{j} \forall i} ( | O^{H} u |^{2} / 36 )^{- s} \,\mathrm{d}u \le ( L^{2} )^{99 ( \varrho + 1 ) ( j + 1 )}.
The argument in briefTake s + 1 orthonormal eigenvectors of C^{H} C with eigenvalue 0; in coordinates adapted to them the integral is a radial integral in s + 1 complex variables.
