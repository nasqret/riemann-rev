lemma Level.stackMeasure_zero_eq

What it saysLet A be a place (class Place: a locally compact Polish commutative ring with involution and Haar measure \,\mathrm{d}x, with an element \tau with \tau + \tau^{*} = 1, a skew unit \delta, a Haar measure \nu_{\mathrm{skew}} on the skew elements, a multiplicative modulus \operatorname{md} : A \to [ 0 , \infty ] such that v \mapsto Mv carries \,\mathrm{d}x to \operatorname{md} ( \det M )^{- 1} \,\mathrm{d}x whenever \det M is a unit, a unitary additive character \psi and a Plancherel constant c); the instances CommRing A, StarRing A, TopologicalSpace A, MeasureSpace A and P : Place A are arguments. Let \mathfrak{s} be a shape, T an \mathfrak{s}-form over A whose Gram matrix J_{T} = splitGram( T ) of V is hermitian and invertible (IsHermUnit), \iota a finite type and m \in \mathbb{N}; G_{T} = U ( J_{T} ), H_{l} = GT ( l ) (fixing e_{a} , e_{a}^{*} for a < l), Q_{l} = unitriGroup( l ), \mathcal{N}_{< l} = unipotentBelow( l ), f_{b} = besselFrame( b ) the frame (f_{b} = e_{b} for b < \varrho, f_{\varrho} = z). Let F be a level (structure Level \iota T m) with measures F.θ and F.μH, unit g_{F} = F.g, ball \mathfrak{B}_{F}, box Bx_{F} and positions Cm_{F}. For j \in \mathbb{N}: stackMeasure( F ) ( 0 , j ) = ( \eta_{0} \ast \cdots \ast \eta_{j - 1} ) \ast ( \theta_{j - 1}^{F} \ast \cdots \ast \theta_{0}^{F} ), i.e. \mathsf{m}_{j}^{F} = ascConv( \eta , j ) \ast descConv( \theta , 0 , j ) with \theta_{a}^{F} = floorMeasure( F , a ).
