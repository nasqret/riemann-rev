lemma BesselSystem.orthonormal

What it saysLet \mathfrak{s} be a shape, b , f the parameters of a Bessel system and B a Bessel system (structure BesselSystem \mathfrak{s} b f: an index type I, a full and a cut Bessel function W(full), W(cut) : G_{1} ( \mathfrak{s} ) \to \mathbb{C}^{I} for an irreducible representation rep of U ( \kappa ), with the cut-pair, Schur and band-limit conditions). Then for all i , j \in I: \int W(full)( y )_{i} \cdot \operatorname{conj}(W(full)( y )_{j}) d \mu ( y ) = 1 if i = j and 0 otherwise, \mu = besselQuotMeasure (integration over \mathsf{U} \setminus G_{1} ( \mathfrak{s} )): the coordinates of the full Bessel function are orthonormal in L^{2} ( \mathsf{U} \setminus G_{1} ( \mathfrak{s} ) ).
The argument in briefThe Gram matrix of the coordinates commutes with the irreducible representation, so it is scalar; the trace fixes the scalar to 1.
