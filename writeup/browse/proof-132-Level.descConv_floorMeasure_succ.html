What it saysLet A be a place (class Place: a locally compact Polish commutative ring with involution and Haar measure \,\mathrm{d}x, with an element \tau with \tau + \tau^{*} = 1, a skew unit \delta, a Haar measure \nu_{\mathrm{skew}} on the skew elements, a multiplicative modulus \operatorname{md} : A \to [ 0 , \infty ] such that v \mapsto Mv carries \,\mathrm{d}x to \operatorname{md} ( \det M )^{- 1} \,\mathrm{d}x whenever \det M is a unit, a unitary additive character \psi and a Plancherel constant c); the instances CommRing A, StarRing A, TopologicalSpace A, MeasureSpace A and P : Place A are arguments. Let \mathfrak{s} be a shape, T an \mathfrak{s}-form over A whose Gram matrix J_{T} = splitGram( T ) of V is hermitian and invertible (IsHermUnit), \iota a finite type and m \in \mathbb{N}; G_{T} = U ( J_{T} ), H_{l} = GT ( l ) (fixing e_{a} , e_{a}^{*} for a < l), Q_{l} = unitriGroup( l ), \mathcal{N}_{< l} = unipotentBelow( l ), f_{b} = besselFrame( b ) the frame (f_{b} = e_{b} for b < \varrho, f_{\varrho} = z). Let F be a level (structure Level \iota T m) with measures F.θ and F.μH, unit g_{F} = F.g, ball \mathfrak{B}_{F}, box Bx_{F} and positions Cm_{F}. For l < \varrho (hypothesis h) and i \in \mathbb{N}: the descending convolution \theta_{l + i}^{F} \ast \cdots \ast \theta_{l}^{F} of the i + 1 floor measures \theta_{a}^{F} = floorMeasure( F , a ) from l on equals (weylLaw( l ) \ast ( \theta_{l + i}^{F} \ast \cdots \ast \theta_{l + 1}^{F} ) ) \ast \eta_{l}, where weylLaw( l ) is the law of w_{l} ( c )^{- 1} under \operatorname{md} ( c )^{k + 1 + 2 ( \varrho - l - 1 )} \,\mathrm{d}c and \eta_{l} = heisenbergMeasure( l ).
