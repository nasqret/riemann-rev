What it saysLet L be a lattice datum, a \in \mathbb{N} and n \in \mathbb{Z}. There are m \in \mathbb{N}, t_1, \ldots, t_m \in galMonoid(k) and \upsilon \in A_{\mathrm{inf}} such that for every x \in kisinLoc(L) and \mu \in \operatorname{forms}(L): if valueAt(L, a, \mu, x) - c \in hodgeFil(n) for some c \in K', then there is c' \in K' with valueAt(L, a, \mu, p^{\mathrm{cost}(a, n)}\cdot x + \sum_l \upsilon\cdotzTauUnit^{-1}\cdot(t_l\cdot x - x)) - c' \in hodgeFil(n + 1) (K' the field fixed by \Gamma').
The argument in briefFor n \ne 0 one Galois step, the particular t of exists_depth_step, suffices: with D = \varphi^{-a}(p_a), t\cdot D = \omega'D and B = D^{-n}(V - c), t(V - c) - (V - c) = (\omega'^{n} - 1)(V - c) + \omega'^{n}D^{n}(tB - B), where tB - B \in hodgeFil(1) because t satisfies p_a | ts - s on S (smul_sub_mem_hodgeFil_of_valueField; Galois differences on the value field do not raise the filtration in general), and (\omega'^{n} - 1)/\varphi^{-a}(z\tau) = \varphi^{-a}(X) with \upsilon X \equiv p^{\mathrm{cost}} modulo p_a. For n = 0 the p^{\mathrm{cost}(a,0)} elements of exists_depth_step_zero average the value into the fixed field modulo t.
