lemma Data.Pair.log_norm_map_norm_sq_trivialLift

What it saysFor parameters P, admissible data D, a finite index type n and \sigma \in Gal(\mathbb{C}/K(P)) there is a real c such that for every pair p of D with H : HasLiftRank(p, n) (|n| = 2z, z \ge 2) there is a real r with -4f \le r, r \le 4f if p is flat (IsFlat(p, n): c_{\tau} = z at every \tau), and \log |\sigma(\lVerttrivialLift(H, 1)\rVert^{2})| = c + r + \sum_{\tau} jetSize(D, c_{\tau} - z): the untwisted lift's squared norm, conjugated by \sigma, is c plus a bounded error plus \sum_{\tau}(\log \lambda_{\tau}! - \lambda_{\tau} \log(\Omega /g)) with \lambda_{\tau} = c_{\tau} - z (Data.jetSize).
The argument in briefConjugate \Xi by \sigma with LValueData.map_trivialLift: \sigma(\lVert \Xi \rVert^{2}) is |t|^{2\sum \mathit{dg}}|l|^{2} times \lVert \Xi_{Y}\rVert^{2} for the conjugate character; insert the L-value formula, bound \log |L| by 4f, and collect the factorials of the hook number and the scales into jetSize.
