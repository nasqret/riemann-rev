lemma Data.gridChar_det

What it saysFor admissible data D, an m-fold twist \vartheta, c, l, a finite index type n, a finite index type n', signs s and k \in K_{0} of rank n': gridChar(\vartheta, c, l, n) at \det(1, k) equals charOfTamePart(gridModulus(\vartheta), gridTamePart(\vartheta, c, l)) at \det(k mod \mathfrak{m}): the character modulo \mathfrak{m} with local components (\omega_w\psi_{\vartheta,w})^{l+1} if c, else \omega_w^{l+1}, evaluated at the reduction of \det k, whatever n is.
