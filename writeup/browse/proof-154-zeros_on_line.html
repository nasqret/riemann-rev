lemma New.zeros_on_line

What it saysIf DirichletLNonvanishingRightOfHalf holds (hypothesis h), then DirichletLZerosOnLine holds: for every natural number N \ne 0 (instance NeZero N), every Dirichlet character \chi modulo N and every complex s with 0 < \operatorname{Re} s, \operatorname{Re} s < 1 and L(s, \chi ) = 0, one has \operatorname{Re} s = 1/2.
The argument in briefTrichotomy for \operatorname{Re} s against 1/2; right of 1/2 by hypothesis, left of it by the symmetry of zeros.

    Let N \ne 0 (instance), \chi a Dirichlet character modulo N, and s with 0 < \operatorname{Re} s < 1 and L(s, \chi ) = 0. If \operatorname{Re} s > 1/2, h gives L(s, \chi ) \ne 0 (s \ne 1 as \operatorname{Re} s < 1), impossible. If \operatorname{Re} s < 1/2, the symmetry of zeros (LFunction_one_sub_eq_zero, applicable as \operatorname{Re} s \ne 0 and s \ne 1) gives: the gamma factor of \chi vanishes at s, impossible because it is \Gamma _\mathbb{R}(s) or \Gamma _\mathbb{R}(s + 1) and \Gamma _\mathbb{R} has no zero on \operatorname{Re} > 0; or L(1 - s, \chi ^{-1}) = 0, which h excludes as \operatorname{Re}(1 - s) > 1/2 and 1 - s \ne 1. Hence \operatorname{Re} s = 1/2.
