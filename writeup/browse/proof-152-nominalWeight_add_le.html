lemma Data.nominalWeight_add_le

What it saysFor parameters P, admissible data D over P and an infinite place \sigma \in \Phi (D): nominalWeight(D, \sigma ) + x(D)^{42} \le 2\cdot b(D).
The argument in briefnominalWeight(D, \sigma ) \le a(D)/x(D) \le (x(D)\cdot b(D) + N_1(D))/x(D) = b(D) + N_1(D)/x(D), so it suffices that N_1(D)/x(D) + x(D)^{42} \le b(D), a comparison of monomials in the scales.
