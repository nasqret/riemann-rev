deflambdaClass

Definition 2.4 of the note · unit 151 · New/Endgame/PrimeError.lean, line 25

The weight of the prime sums. For a natural number d that is prime (instance Fact (Nat.Prime d)), a natural number M and a natural number \nu: \lambda_{d,M}(\nu) = \Lambda(\nu)\cdot(1 - \chi_d(\nu)) if \nu \equiv 1 mod M (that is, (\nu : \mathbb{Z}/M) = 1), and \lambda_{d,M}(\nu) = 0 otherwise; \Lambda is von Mangoldt's function (Mathlib's vonMangoldt.residueClass) and \chi_d(\nu) = (\nu/d) \in \{-1, 0, 1\} is the Legendre symbol, i.e. the quadratic character of \mathbb{Z}/d (chiK d), read as a real number. \Lambda(\nu) \ne 0 only for prime powers \nu = p^{j} (j \ge 1), so the congruence \nu \equiv 1 mod M is a condition on p^{j}, not on p, and \chi_d(p^{j}) = \chi_d(p)^{j}: the factor 1 - \chi_d(\nu) is 0 when \chi_d(p) = 1; when \chi_d(p) = -1 it is 2 for odd j and 0 for even j; and it is 1 when p = d. The definition allows every prime d. Only for d \equiv 3 mod 4 (as in the later criterion, where d \equiv 7 mod 8) is \chi_d the quadratic character of \mathbb{Q}(\sqrt-d), so that \chi_d(p) = -1 means that p is inert in \mathbb{Q}(\sqrt-d); for d = 5 and p = 3, (3/5) = -1 although 3 splits in \mathbb{Q}(\sqrt-5).

defIsPolar

Definition 2.8 of the note · unit 107 · Lib/Analytic/Landau/PolarLandau.lean, lines 34–36
