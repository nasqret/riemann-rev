lemma volume_sum_mem_Icc_le

What it saysFor n \in \mathbb{N} and reals d \le D (hd), D of either sign: the Lebesgue measure of \{y \in \mathbb{R}^{n+1} : y \ge 0 and \sum_{b} y(b) \in [d - 1, d]\} is at most \lVert D^{n}/n!\rVert_{e} = |D^{n}/n!| (as an extended nonnegative real). (When d \le D < 0 the set is empty, since \sum_{b} y(b) \ge 0 > d.)
The argument in briefInduction on n through recursion, for D of either sign: integrate over the first coordinate x the bound |(D - x)^{n}/n!| for the remaining n coordinates at the level d - x \le D - x. The slice at x is empty unless 0 \le x \le d \le D, so the integrand is supported in the unordered interval between D and 0 (uIcc D 0; when D < 0 the set is empty), and \int over uIoc D 0 of |D - x|^{n}/n! \mathit{dx} = |D|^{n+1}/(n+1)! = \lVert D^{n+1}/(n+1)!\rVert.
