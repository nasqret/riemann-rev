lemma SquareLaw.sum_fourier_eq_nextDatum

What it saysLet R be a finite commutative ring, N, T finite index types, \chi a primitive multiplicative character (h\chi) and \psi a primitive additive character (h\psi) of R. There is \gamma \in \mathbb{C} with |\gamma |^{2}\cdot |R|^{t(t+2n)} = 1 (n = \#N, t = \#T) such that for all c, L, L' and every function p on N \times T matrices: if SquareLaw(\chi, swapFirstTwo, c, L, L') holds for the identification (N \sqcup T) \sqcup (N \sqcup T)-type swap of the first two summands (with a = N \sqcup T, b = T, n = N), then \sum_{y} \mathcal{F}(\overline{p})(y)\cdot L'(fromRows(y, 1_{0})) = \gamma \cdot c\cdot \sum_{x} \mathcal{F}(\operatorname{conj}(nextDatum(p)))(x)\cdot L(fromCols(1_{0}, x)), where \mathcal{F} = matrixFourier(\psi, \cdot) is the finite Fourier transform and 1_{0} the standard inclusion matrix.
The argument in brief\gamma is the conjugate Gauss sum divided by the number of matrices; apply SquareLaw.sum_eq_nextDatum to the Fourier transform of \overline{p} and compute the Fourier transform of the next datum with the matrix Gauss sum.
