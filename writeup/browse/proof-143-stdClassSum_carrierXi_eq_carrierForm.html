lemma stdClassSum_carrierXi_eq_carrierForm

What it saysLet E be a field with a CM type and Weil data, and m a natural number with m \ne 0 (instance NeZero m) and m even (he). Then there is C such that for every modulus \mathfrak{m}, character c and multiplicative character \chi of O_E/\mathfrak{m} with c tame for (\mathfrak{m}, 0, \chi) (weight 0), there is \gamma with |\gamma |^2 = C / (\operatorname{lValueProd}(\operatorname{places} \text{ of } \mathfrak{m}, c^{-1}\cdot \upsilon^m, m)\cdot \operatorname{lValueProd}(\operatorname{places} \text{ of } \mathfrak{m}, c\cdot \upsilon^{m/2}, m/2)) and, for every point x, \gamma \cdot \sum_h carrierXi m c h\cdot \theta^{S, I_{3m}}_{\upsilon^m, c}[\chi \circ \det, 1](x, h) = carrierForm E m x, where S = signedSpace with signs (+1 \text{ on } \operatorname{Fin} (2m), -1 \text{ on } \operatorname{Fin} m), of signature (2m, m); the outer kernel pairs S with the definite space I_{3m} on the same index set \operatorname{Fin} (2m) \oplus \operatorname{Fin} m (the determinant datum \chi \circ \det needs square matrices), and the outer sum is the class sum over U(I_{3m}) at level K_0, h running over its classes; carrierXi m c h is itself a class sum over U(I_m) (of the kernel of the pair (I_m, I_{3m})). The constant C comes first; \gamma depends on (\mathfrak{m}, c, \chi).
The argument in briefThree inputs: negation of the first space conjugates kernels; the class sum of stdClassSum_det_modKernel_eq for c = 0; explicit matching for W = I_m \oplus (signed space), V' = -I_m. Then explicit_matching_of_sum with the trivial modulus and the seesaw rule give the carrier.
