lemma matchingPairs.exists_linear_factor

What it saysLet F be a semilocal field, a, b, n finite index types, \chi a multiplicative character of F which is tame (h\chi), e : b \sqcup a \simeq n, X any type and \Lambda a linear map from complex functions on a \times n matrices to functions X \to \mathbb{C} such that \chi(\det g)\cdot \Lambda(\Phi(g\cdot)) = \Lambda(\Phi) for every g \in \mathrm{GL}_a(F) and every Schwartz–Bruhat \Phi supported on surjective matrices (h\Lambda). Then there is a linear map T from complex functions on n \times b matrices to functions X \to \mathbb{C} with T(\Psi) = \Lambda(\Phi) for every pair (\Phi, \Psi) in matchingPairs(\chi, e).
The argument in briefDefine T(\Psi) as \Lambda of the function x \mapsto \chi(\det k_x)\cdotlocalSection(\chi, firstCols(e, k_x))(\Psi) on primitive x (k_x \in \mathrm{GL}_n(O) with x = invLastRows(e, k_x)); for a matched pair, cover the support of \Phi by finitely many translates of the primitive set and use the invariance of \Lambda.
