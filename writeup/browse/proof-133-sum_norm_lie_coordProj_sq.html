lemma sum_norm_lie_coordProj_sq

What it saysLet n be a finite index type, w : n \to \mathbb{Z} and X a complex n \times n matrix; put a = \sum_{j} | w_{j} | and, for t \in \mathbb{Z}, let P_{t} = coordProj( \{ i : t \le w_{i} \} ) be the diagonal projection onto the coordinates i with w_{i} \ge t. Then ( 1 ) \sum_{t = - a + 1}^{a} \lVert [ P_{t} , X ] \rVert^{2} = gapWeightedNormSq( w , X ), with the Frobenius norm and [ P , X ] = PX - XP, and ( 2 ) \sum_{t = - a + 1}^{a} \operatorname{tr} ( P_{t} \cdot X ) = \sum_{i} ( w_{i} + a ) \cdot X_{ii}.
The argument in briefEntrywise, [ P_{t} , X ]_{ij} = ( 1_{w_{i} \ge t} - 1_{w_{j} \ge t} ) X_{ij} and ( P_{tX} )_{ii} = 1_{w_{i} \ge t} X_{ii}; summing over t \in ( - a , a ] counts the integers t between w_{j} and w_{i} (giving | w_{i} - w_{j} |) and those in ( - a , w_{i} ] (giving w_{i} + a).
