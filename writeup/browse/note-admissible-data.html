Structure. Admissible data D over parameters P consist of: real numbers \mathit{logX}(D), \mathit{logB}(D), \mathit{logX}_1(D) (the logarithms of the scales x, b, x_1); natural numbers s(D), m(D), r(D); a finite set \operatorname{thick}(D) of infinite places of E(P, s(D)); (scale) 10^{12}\cdot c(P) \le \log \mathit{logB}, 100\cdot \log \mathit{logB} \le \mathit{logX}, 10^{6}\cdot \mathit{logX} \le \mathit{logX}_1, 10^{6}\cdot \mathit{logX}_1 \le \mathit{logB} and 6\cdot \log \mathit{logX}_1 \le \log \mathit{logB}, that is, with x = e^{\mathit{logX}}, x_1 = e^{\mathit{logX}_1}, b = e^{\mathit{logB}}: (\log b)^{100} \le x, x^{10^{6}} \le x_1, x_1^{10^{6}} \le b, (\log x_1)^{6} \le \log b and 10^{12}\cdot c(P) \le \log \log b; (r_{\mathrm{pow}}) there is a natural number e with r = 3^{e+1}; (thick_eq_neg_one_mod) for every natural number m' and every proof h of m' \mid N_1(P, s): if m' divides N_0(P)\cdot 3^{\lfloor \log _3 s\rfloor +5}, then placeClass(P, h)(\sigma ) = -1 in (\mathbb{Z}/m')^\times for every \sigma \in \operatorname{thick} (the Lean binder is named m and hides the field m); classData.HasLogBound

Definition 3.1 of the note · unit 152 · New/Data/Magnitudes.lean, lines 18–19

Class. For parameters P, admissible data D over P, a Boolean u, a real number F and a real number l (an output parameter: instance search computes it from the shape of F), HasLogBound(D, u, F, l) is the proposition (its only field out) that |F| \le \exp (l) if u is true and \exp (l) \le F if u is false. The data D only index the class, so that instances can name the quantities of D. The exponent is not determined by F: a bound holds for many l (already for F = 1), and instance search returns the one exponent that the selected instance supplies, which may also depend on bounds present in the local context.
