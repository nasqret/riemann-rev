lemma obeyingCocycles.mem_selmerModule

What it saysLet \ell be a prime, D admissible data for parameters P with field E = D.E, Y, n and r finite types and O a coefficient ring (the ring of integers of a finite Galois extension of \mathbb{Q}_\ell inside \overline{\mathbb{Q}}_\ell). Let u = (u_x)_{x\in Y} be a family of homomorphisms u_x : \operatorname{Gal}(\Omega /E) \to M_n(O) into the multiplicative monoid of n\times n matrices, each continuous (hc); let S be a set of finite places of E such that u_x(g) = 1 for every x \in Y and every g in the inertia above a place of E outside S (hS); let \rho : \operatorname{Gal}(\Omega /E) \to M_r(O) be a homomorphism, b \in O with b \ne 0 (NeZero b), c : \operatorname{Gal}(\Omega /E) \to (O/bO)^r a function and L a set of relations (finitely supported functions \operatorname{Gal}(\Omega /E) \to M_r(O)). If c \in obeyingCocycles u \rho b (h: c is a cocycle for \rho modulo b, continuous or not, with \sum _g \theta (g)c(g) = 0 for every finitely supported \theta : \operatorname{Gal}(\Omega /E) \to O such that \sum _g \theta (g)(u_x(g) - 1) = 0 for all x) and c obeys L (l: c \in obeying L (O/bO)), then c lies in the Selmer module selmerModule \rho S L (O/bO): c is a locally constant cocycle for \rho, vanishes on the inertia above every place outside S, and obeys L.
The argument in briefBy Artin–Rees (exists_graph_subrepresentation) c is, on the elements (u(g) - 1) + b^k\cdot v, the value of a map whose graph Y is a subrepresentation with injective first projection. Hence c vanishes where all u_x(g) = 1 (on the inertia off S), and c(h) = c(g) whenever u(h) \equiv u(g) \bmod b^k, which is an open condition since the u_x are continuous: c is locally constant. Cocycle and L-relations are given.
