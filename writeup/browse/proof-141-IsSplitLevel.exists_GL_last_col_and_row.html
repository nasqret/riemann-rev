lemma IsSplitLevel.exists_GL_last_col_and_row

What it saysFor a finite index type n and a commutative ring R: there is a map k from vectors of length n + 1 over R to \mathrm{GL}_{n+1}(R) such that every vector y whose last entry is a unit of R is both the last column and the last row of k(y). (Construction: with C the identity matrix whose last column is replaced by y, k(y) = y_{\mathrm{last}}^{-1}\cdot C\cdot C^{T}.)
The argument in briefk(y) = y_{\mathrm{last}}^{-1}\cdot C\cdot C^{T} with C the identity whose last column is y.

  1. 1witnesslines 100–101

    For y with y_{\mathrm{last}} a unit, let C be the identity matrix with its last column replaced by y; \det C = y_{\mathrm{last}} is a unit (Cramer), so k(y) = y_{\mathrm{last}}^{-1}\cdot C\cdot C^{T} is invertible; for the other y put k(y) = 1.

  2. 2identityline 102

    The last column of C\cdot C^{T} is y_{\mathrm{last}}\cdot y and so is its last row (the columns of C other than the last are standard basis vectors with last entry 0); dividing by y_{\mathrm{last}} gives y.
