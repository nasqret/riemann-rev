lemma exists_partner_kernel

What it saysLet R be a finite commutative ring, a, b, N, n finite index types, \chi a multiplicative character of R, e : b \sqcup a \simeq N \sqcup n, and suppose (R, R) is a valuation pair (val: IsValuationPair ⊤). There is a function d on matrices such that (1) for all x, y: if d(y)\cdotgraphKernel(\chi, e, x, y) \ne 0 then this value is a root of unity (of finite order), a left inverse of the first row block of y gives one of the second column block of x, and a left inverse of the second row block of y gives one of the first column block of x; (2) the average over k \in \mathrm{GL}_b(R) of d(y\cdot k)\cdotgraphKernel(\chi, e, x, y) is graphKernel(\chi, e, x, y); and (3) for all c, L, L' with SquareLaw(\chi, e, c, L, L') and every y one of whose row blocks has a left inverse: L'(y) = c\cdot \sum_{x} graphKernel(\chi, e, x, y)\cdot L(x).
The argument in briefd(y) = \#\mathrm{GL}_b(R) at one chosen point of each orbit y\cdot \mathrm{GL}_b(R) and 0 elsewhere; the kernel values are character values; the square law applied to the partners (graphKernel(\chi^{-1}, e, invLastRows(e, j), \cdot), \Psi) gives (3).
