lemma Parameters.isTightFrame_zeta_pow

What it saysFor parameters P, an exponent s and k \in \mathbb{N}: the family (\zeta^i)_{0 \le i < N_1} in E, each element taken with multiplicity k, is a tight frame of length k\cdot N_1 (IsTightFrame): every \alpha^{-1}\zeta^i is an integral finite adele, and for all infinite places \sigma, \tau: \sum_{i<N_1} k\cdot \Phi_\sigma(\zeta^i)\cdot \operatorname{conj}(\Phi_\tau(\zeta^i)) = k\cdot N_1 if \sigma = \tau and 0 otherwise.
The argument in briefIntegrality from \alpha^{-1} \in \hat{O}; the frame identity is a geometric sum of the root of unity \Phi_\sigma(\zeta)/\Phi_\tau(\zeta).

    The frame identity, for all infinite places \sigma, \tau.

    1. 2.1case-splitlines 62–63

      Split on \sigma = \tau and simplify: the sum is k\cdot \sum_{i<N_1} (\Phi_\sigma(\zeta)\cdot \operatorname{conj} \Phi_\tau(\zeta))^i. If \sigma = \tau every term is |\Phi_\sigma(\zeta)|^{2i} = 1 and the sum is k\cdot N_1; this case is closed.

    2. 2.2caselines 64–66

      If \sigma \ne \tau, put q = \Phi_\sigma(\zeta)\cdot \operatorname{conj} \Phi_\tau(\zeta) = \Phi_\sigma(\zeta)/\Phi_\tau(\zeta). Then q \ne 1: otherwise \Phi_\sigma and \Phi_\tau agree on \zeta, hence on E = K(\zeta) (power basis), hence \sigma = \tau. So the geometric sum is (q^{N_1} - 1)/(q - 1) = 0, since \zeta^{N_1} = 1.
