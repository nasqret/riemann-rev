lemma norm_sq_add_re_trace_le

What it saysLet n be a finite type, \varepsilon : n \to \{ \pm 1 \} signs, g \in U ( \varepsilon ) , a , C \in \mathbb{R} and v , w : n \to \mathbb{Z} such that for all i , j \in n: a \cdot v_{i}^{2} \le w_{i}, and w_{i} \le C whenever \varepsilon_{i} \ne \varepsilon_{j} ( h ). Then a \lVert \operatorname{diag} ( v ) ( g - 1 ) \rVert^{2} + 2 \operatorname{Re} \operatorname{tr} ( \operatorname{diag} ( w ) ( g - 1 ) ) \le 2 C \lVert g - a_{\varepsilon} ( g ) \rVert^{2}, where a_{\varepsilon} ( g ) = blockDiagPart( \varepsilon ) ( g ) is the block-diagonal part of g (the entries g_{ij} with \varepsilon_{i} = \varepsilon_{j}, zero elsewhere) (\lVert \cdot \rVert is the Frobenius norm, the norm in force in this file).
The argument in briefRewrite 2 \operatorname{Re} \operatorname{tr} ( \operatorname{diag} ( w ) ( g - 1 ) ) as \operatorname{Re} \operatorname{tr} ( \operatorname{diag} ( w ) ( g - 1 ) ( 1 - g^{- 1} ) ), expand both sides into double sums over the entries, and compare term by term, using g^{- 1} = \operatorname{diag} ( \varepsilon ) g^{H} \operatorname{diag} ( \varepsilon ).
