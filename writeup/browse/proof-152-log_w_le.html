lemma Data.log_w_le

What it saysFor parameters P, admissible data D over P, a natural number j with hj : j \le 2\cdot m(D) and an infinite place \sigma \in \Phi (D): \log w(D, j, \sigma ) \le \log nominalWeight(D, \sigma ) + x(D)^{-1}.
The argument in briefExponentiate: w(D, j, \sigma ) \le nominalWeight(D, \sigma ) + x(D)^{42} and nominalWeight(D, \sigma )\cdot e^{1/x(D)} \ge nominalWeight(D, \sigma )\cdot (1 + 1/x(D)), so it suffices that x(D)^{42} \le nominalWeight(D, \sigma )/x(D), a comparison of monomials.

    Write \nu for the real number nominalWeight(D, \sigma ) > 0. Since w(D, j, \sigma ) > 0, \log w(D, j, \sigma ) \le \log \nu + 1/x(D) is equivalent to w(D, j, \sigma ) \le \exp (\log \nu + 1/x(D)) = \nu \cdot \exp (1/x(D)); by w(D, j, \sigma ) \le \nu + x(D)^{42} (w_le_nominalWeight_add with hj) and \exp (1/x(D)) \ge 1 + 1/x(D) it suffices that \nu + x(D)^{42} \le \nu \cdot (1/x(D) + 1), i.e. x(D)^{42} \le \nu \cdot x(D)^{-1}; the positivity side conditions are closed with HasLogBound.pos.
