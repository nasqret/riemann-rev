lemma Level.lintegral_floorMeasure_mul_right

What it saysLet A be a place (class Place: a locally compact Polish commutative ring with involution and Haar measure \,\mathrm{d}x, with an element \tau with \tau + \tau^{*} = 1, a skew unit \delta, a Haar measure \nu_{\mathrm{skew}} on the skew elements, a multiplicative modulus \operatorname{md} : A \to [ 0 , \infty ] such that v \mapsto Mv carries \,\mathrm{d}x to \operatorname{md} ( \det M )^{- 1} \,\mathrm{d}x whenever \det M is a unit, a unitary additive character \psi and a Plancherel constant c); the instances CommRing A, StarRing A, TopologicalSpace A, MeasureSpace A and P : Place A are arguments. Let \mathfrak{s} be a shape, T an \mathfrak{s}-form over A whose Gram matrix J_{T} = splitGram( T ) of V is hermitian and invertible (IsHermUnit), \iota a finite type and m \in \mathbb{N}; G_{T} = U ( J_{T} ), H_{l} = GT ( l ) (fixing e_{a} , e_{a}^{*} for a < l), Q_{l} = unitriGroup( l ), \mathcal{N}_{< l} = unipotentBelow( l ), f_{b} = besselFrame( b ) the frame (f_{b} = e_{b} for b < \varrho, f_{\varrho} = z). Let F be a level (structure Level \iota T m) with measures F.θ and F.μH, unit g_{F} = F.g, ball \mathfrak{B}_{F}, box Bx_{F} and positions Cm_{F}. Let l \in \mathbb{N}, S a subgroup of G_{T} containing H_{l} (hypothesis hS), f : G_{T} \to [ 0 , \infty ] measurable (hypothesis hf, by default discharged by fun_prop) and left invariant under Q_{l + 1} \cap S (hypothesis hi: f ( \gamma x ) = f ( x ) for \gamma \in Q_{l + 1} \cap S), and s \in Q_{l} \cap S (hypothesis hs). Then \int f ( xs ) d \theta_{l}^{F} ( x ) = \int f d \theta_{l}^{F}, \theta_{l}^{F} = floorMeasure( F , l ).
The argument in briefWrite s = \gamma \nu; remove \nu by invariance; remove \gamma through the factorization of f by \sigma \mapsto \sigma^{- 1} f_{l}, using that left translation by \gamma^{- 1} preserves \delta_{F}^{l}.
