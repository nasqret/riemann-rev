lemma IsAdmissibleComb.normUnit_smul

What it saysLet \alpha be a type, Z a complex vector space, v : \alpha \to Z, A \subseteq \alpha, n, d natural numbers with d \ne 0 (hypothesis hd), p a proposition, B real, z \in Z, and C, a \in \mathbb{C}. If (premise) IsAdmissibleComb(x \mapsto C\cdot v(x), A, n, d, p, B, z), then IsAdmissibleComb(v, A, n, 1, p, d\cdot B, normUnit(a\cdot C/d)\cdot a\cdot z), where normUnit(w) = w^{-1} for w \ne 0 and normUnit(0) = 1. If a\cdot C \ne 0, the scalar normUnit(a\cdot C/d)\cdot a is d/C, which clears both the factor C and the denominator d. If a\cdot C = 0, normUnit(a\cdot C/d) = 1 and the vector normUnit(a\cdot C/d)\cdot a\cdot z is 0 (for a = 0 directly; for C = 0 because z is a combination of the vectors C\cdot v(x) = 0); e.g. a = 0, d = C = 1 and z \ne 0 give the zero vector, not (d/C)\cdot z. No hypothesis a\cdot C \ne 0 is made.
The argument in briefMultiply the coefficients by d: the combination d\cdot r of the v(x) has denominator 1 and size d\cdot B, and normUnit(aC/d)\cdot a\cdot z is \operatorname{normalize}(aC/d) \in \{0, 1\} times it.

  2. 2deductionlines 81–83

    The coefficients d\cdot r give an admissible combination z' = \sum_{x} d\cdot r(x)\cdot v(x) of the v(x) with denominator 1 and size d\cdot B under p. Let \zeta = \operatorname{normalize}(a\cdot C/d), which is 1 if a\cdot C \ne 0 and 0 otherwise. Then normUnit(a\cdot C/d)\cdot a\cdot z = \zeta\cdot z': if a\cdot C \ne 0 the left side is (d/(aC))\cdot a\cdot C\cdot\sum r(x) v(x) = z', and if a\cdot C = 0 both sides vanish. Since \zeta is 0 or a root of unity, smul_of_eq_zero_or_isOfFinOrder gives the claim; the identity of the two sides is checked by simp and field_simp.
