lemma Level.measurableSet_isNear

What it saysLet A be a place (class Place: a locally compact Polish commutative ring with involution and Haar measure \,\mathrm{d}x, with an element \tau with \tau + \tau^{*} = 1, a skew unit \delta, a Haar measure \nu_{\mathrm{skew}} on the skew elements, a multiplicative modulus \operatorname{md} : A \to [ 0 , \infty ] such that v \mapsto Mv carries \,\mathrm{d}x to \operatorname{md} ( \det M )^{- 1} \,\mathrm{d}x whenever \det M is a unit, a unitary additive character \psi and a Plancherel constant c); the instances CommRing A, StarRing A, TopologicalSpace A, MeasureSpace A and P : Place A are arguments. Let \mathfrak{s} be a shape, T an \mathfrak{s}-form over A whose Gram matrix J_{T} = splitGram( T ) of V is hermitian and invertible (IsHermUnit), \iota a finite type and m \in \mathbb{N}; G_{T} = U ( J_{T} ), H_{l} = GT ( l ) (fixing e_{a} , e_{a}^{*} for a < l), Q_{l} = unitriGroup( l ), \mathcal{N}_{< l} = unipotentBelow( l ), f_{b} = besselFrame( b ) the frame (f_{b} = e_{b} for b < \varrho, f_{\varrho} = z). Let F be a level (Level \iota T m: measures F.θ, F.μH, unit g_{F}, ball \mathfrak{B}_{F}, box Bx_{F}, positions Cm_{F}) and \Gamma a gauge for F (sets B_{j}^{\Gamma} = \Gamma .ofSize( j ), constant \Lambda_{\Gamma}); E_{b}^{F} = floorBasis( F , b ) is the basis matrix of V_{b} ( b \le \varrho ) made of F's basis of V_{\varrho} and the pairs ( e_{a} , e_{a}^{*} ) , a \ge b. For every j, the set \{ g \in G_{T} : IsNear( F , j , g ) \} is measurable.
The argument in briefThe set of near points is Q_{j} \cdot Bx_{F}, closed times compact.
