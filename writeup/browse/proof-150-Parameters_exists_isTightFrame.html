lemma Parameters.exists_isTightFrame

What it saysFor parameters P, an exponent s, a prime p with a p-adic place \iota_p \colon \mathbb{C} \to \mathbb{C}_p (instance), and natural numbers m, R with (d\cdot N_1)^6\cdot(R + 1) \le m: there are a finite type I, vectors v \colon I \to E and multiplicities c \colon I \to \mathbb{N} such that (v, c) is a tight frame of length m (IsTightFrame v c m: \alpha^{-1}v_i \in \hat{O} for all i and \sum_i c_i\cdot \Phi_\sigma(v_i)\cdot \operatorname{conj}(\Phi_\tau(v_i)) = m\cdot [\sigma = \tau] for all infinite places \sigma, \tau), R \le c_i for every i, and for some index i, |\iota_p(s_1\cdot \operatorname{conj}(\Phi_\tau(v_i)))|_p = 1 for every infinite place \tau(s_1 = \operatorname{periodFactor}(P, s)).
The argument in briefGlue two tight frames: the frame (\zeta^i)_{i<N} (N = N_1) of length N, and a frame (u_{l, j, k, i}) of length c built for each prime factor l of N from the primitive l-th root of unity a_l = \zeta^{r_l} and t = 1 - c_0 + nz (n = (d+1)/4, N \mid nz^2 + z + 1). Since \gcd(c, N) = 1 and m - R(c + N) \ge(N - 1)(c - 1), m - R(c+N) = A\cdot c + B\cdot N (Frobenius), and multiplicities A + R, B + R give length m (the length is the scalar of the weighted Gram identity, not a count of vectors). Integrality of \alpha^{-1}u uses \Phi_N'(\zeta)(\zeta^r - 1)M = N\cdot V. The unit index: the first candidate is the vector 1 = \zeta^0; only if |\iota_p(s_1\cdot \operatorname{conj} \Phi_\tau(1))| \ne 1 for some \tau does the proof deduce p \mid N and take u_{p, 0, 1, 0}; the index chosen works for every \tau at the fixed (p, \iota_p).
