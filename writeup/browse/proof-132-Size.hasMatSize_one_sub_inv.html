lemma Size.hasMatSize_one_sub_inv

What it saysLet A be a commutative ring with involution (CommRing A, StarRing A ) , \mathfrak{s} a shape and T an \mathfrak{s}-form over A; V is the free A-module on the basis e_{0} , \ldots , e_{\varrho - 1} , ( x_{i} )_{i \in \kappa} , z , e_{\varrho - 1}^{*} , \ldots , e_{0}^{*} with Gram matrix J_{T} = splitGram( T ) and U ( J_{T} ) its unitary group; assume J_{T} is hermitian and invertible, let S be a size for T , c , j \in \mathbb{N}, u \in U ( J_{T} ) and r \in A^{x}. If u \in \mathcal{N}_{< j} = unipotentBelow( j ) (hypothesis hu), r^{*} = r and r \in B_{1}^{S} (hypothesis hr), and for every pair index a < j there is a vector w with w ( e_{b}^{*} ) = \delta_{ab} for all b \le a, w \in vecsOfSize( S , c ) and ( r^{- 1} ( 1 - u ) ) \cdot w \in vecsOfSize( S , c ) (hypothesis h), then the matrix r^{- 1} ( 1 - u^{- 1} ) has size c + 4 + ( 2 c + 8 ) j.
The argument in briefBack substitution: row_mem_ofSize_of_dual_frame for X = r^{- 1} ( 1 - u^{- 1} ) with the vectors uw, its base case from J_{T} \cdot X = ( r^{- 1} ( 1 - u ) )^{H} \cdot J_{T} and the same lemma for r^{- 1} ( 1 - u ).
