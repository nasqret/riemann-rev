What it saysLet n and X be finite types, \varepsilon : n \to \{ \pm 1 \} signs, l : n \to \mathbb{Z} a doubled Harish-Chandra parameter for \varepsilon , u an X \times X complex matrix, \sigma : X \to n a map with \varepsilon ( \sigma ( x ) ) = 1 and \Lambda ( l ) ( \sigma ( x ) ) = 0 for every x \in X ( z ), and k , g , t \in U ( \varepsilon ) with k - 1 = \iota_{\mathbb{C}} ( \sigma ) ( u \cdot \iota_{\mathbb{C}} ( \sigma )^{H} ) (hk) and t = kg ( e ), where \iota_{\mathbb{C}} ( \sigma ) = inclMatrix( \mathbb{C} , \sigma ). Then ( 1 ) \operatorname{diag} ( \Lambda ( l ) ) ( k - 1 ) = 0; ( 2 ) \psi_{l} ( t ) = \psi_{l} ( g ); and ( 3 ) \lVert t - 1 \rVert^{2} + 2 \operatorname{Re} \operatorname{tr} ( t - 1 ) \le 2 \lVert g - a_{\varepsilon} ( g ) \rVert^{2} (\lVert \cdot \rVert is the Frobenius norm, the norm in force in this file).
