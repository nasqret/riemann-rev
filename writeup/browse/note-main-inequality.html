defRiemannZetaZerosOnLine

Definition 2.1 of the note · unit 153 · Statements.lean, lines 3–4

The proposition RiemannZetaZerosOnLine (the Riemann hypothesis): for every complex number s, if \zeta(s) = 0, if s is not of the form -2(n + 1) for any natural number n (that is, s is none of the trivial zeros -2, -4, -6, \ldots), and if s \ne 1, then \operatorname{Re} s = 1/2. Here \zeta is Mathlib's riemannZeta, the meromorphic continuation of \sum_{n\ge 1} n^{-s} to \mathbb{C}; Mathlib defines it at every complex number, also at the pole s = 1, where it takes a conventional finite value.

defDirichletLNonvanishingRightOfHalf

Definition 2.1 of the note · unit 153 · Statements.lean, lines 6–8

The proposition DirichletLNonvanishingRightOfHalf (the generalised Riemann hypothesis for Dirichlet L-functions, in half-plane form): for every natural number N with N \ne 0 (Lean's instance argument NeZero N), every Dirichlet character \chi modulo N with complex values, and every complex number s with 1/2 < \operatorname{Re} s, if \chi is not the principal character modulo N or s \ne 1, then L(s, \chi) \ne 0. Here L(s, \chi) is Mathlib's DirichletCharacter.LFunction χ s, the meromorphic continuation of \sum_{n\ge 1} \chi(n) n^{-s} (for the principal character it has a pole at s = 1, where Mathlib assigns a conventional value); a Dirichlet character modulo N is Mathlib's DirichletCharacter ℂ N, a multiplicative map \mathbb{Z}/N \to \mathbb{C} that vanishes off the units, and 1 is the principal character modulo N (1 on the units, 0 elsewhere).

defIsPolar

Definition 4.1 of the note · unit 107 · Lib/Analytic/Landau/PolarLandau.lean, lines 34–36

IsPolar(E, r) for E : ℝ → ℝ and r : ℂ → ℂ: E is measurable and there are a real C and a meromorphic Φ : ℂ → ℂ with |E(v)| ≤ C·e^v for v ≥ 0, Φ(s) = ∫_0^∞ E(v)e^((1−s)v) dv for Re s > 2, (s − 1)Φ(s) analytic near every point of Re s ≥ 1, and (z − ρ)Φ(z) → r(ρ) as z → ρ, z ≠ ρ, for every ρ with Re ρ > 0. Since Φ is a function defined at s = 1, the product (s − 1)Φ(s) vanishes at s = 1, so the analyticity says that Φ has no pole at 1 (off s = 1 it agrees with a function holomorphic near 1), as the source's doc comment says; read in ordinary notation without that value, '(s − 1)Φ(s) analytic' would still allow a simple pole.
