lemma Parameters.chiK_eq_one_of_dvd

What it saysFor parameters P, a natural number p, an exponent s, hp : p is prime and h : p \mid N_1(P, s): \chi _K(p) = (p/d(P)) = 1, where \chi _K = chiK(d(P)) is the Legendre symbol \bmod d(P); so p splits in K = \mathbb{Q}(\sqrt{-d(P)}).
The argument in briefWith 4p \mid d(P) + 1, the Legendre symbol (p/d(P)) equals the Jacobi symbol (p | 4p - 1), which is 1.

    \chi _K(p) is the Legendre symbol (p/d(P)), i.e. the Jacobi symbol J(p | d(P)); reducing d(P) modulo 4p (jacobiSym.mod_right'), d(P) \bmod 4p = 4p - 1 since 4p \mid d(P) + 1; and 1 = J(1 | 4p - 1) = J(4p | 4p - 1) (the upper entry is read modulo 4p - 1). So it remains J(p | 4p - 1) = J(4p | 4p - 1), together with the side conditions (p > 0, 4p \mid d(P) + 1, d(P) odd).
