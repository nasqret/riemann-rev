lemma Lift.KummerChart.PairingSide.exists_relLength_deepConstants_le

What it saysLet the chart be unramified (hk), p \ge 5 (hp), S a side, a, \eta, W \in \mathbb{N}, b, n, r : letters \to \mathbb{N} and \varepsilon : letters \to \mathbb{Z}^\times such that for every letter j: b(j) + W + \eta \le (p - 3)\cdot a (ha); 6(a + \eta + W) < b(j) (hb); NoMultipleNear(p, 6(a + \eta + W), b(j)) (hs: p divides no nonzero integer within 6(a + \eta + W) of 0, b(j) or -b(j)); the jump set U_j of S lies in [-\eta, \eta] \cup \varepsilon(j)\cdot[b(j), b(j) + W] (hU: IsInJumpWindow(\eta, \varepsilon(j), b(j), W, U_j)); f\cdot\sum_{u\in[-\eta, \eta]} jumpMultiplicity(Y, j, u) \le n(j) (hn); and f\cdot\sum_{u\in U_j} jumpMultiplicity(Y, j, u) \le r(j) (hr) (f the residue degree of the chart, Y the lattice of S). (\eta \ge 1 is not assumed.) Then for every letter i: relLength(range(constantAt(S, i)), deepConstants(S, i, 0, c_i)) \le (2a + 1)\cdot n(i) + 3(W + 1)\cdot r(\sigma^{-1}(i)) + 6a\cdot n(\sigma^{-1}(i)), where c_i = raisedAtE(2a + \eta) if \varepsilon(i) = 1, and otherwise c_i(1, u) = W + 1 - u + (2a if |u| \le \eta, else 0), c_i(0, u) = b(i) + W + 2a, c_i(l, u) = -u for l \ge 2.
The argument in briefFirst raise the exponent at E from -\eta to 0 for constants lifting with depth raisedAtE(2a + \eta), each step costing a\cdot(low jump count) (h₁); for \varepsilon(i) = 1 this is the claim. Otherwise two applications of relLength_deepConstants_le: from the lifted depth to raisedAtE(qp + u) at E (q\cdot p the least multiple of p that is \ge b(i) + W + 2a: b(i) + W + 2a \le q\cdot p < b(i) + W + 2a + p, existsUnique_add_zsmul_mem_Ico — not the quotient of a Euclidean division, which rounds down), then to the stated depth, with costs bounded by Legendre's formula and the gap condition.
