What it saysDirichletLNonvanishingRightOfHalf holds: for every natural number q \ne 0 (instance NeZero q), every Dirichlet character \chi modulo q with complex values and every complex number \rho with 1/2 < \operatorname{Re} \rho, if \chi is not the principal character or \rho \ne 1, then L(\rho , \chi ) \ne 0 (Mathlib's DirichletCharacter.LFunction).
The argument in briefA zero of L(s, \chi ) right of 1/2 is a zero of \tilde{L} for the induced character modulo N_0 = 18480q; the one-sided criterion (Landau) with the class N_0/2 - 1 excludes it, because every prime d of that class gives parameters (N_0, d), for which the one-sided bound holds.
