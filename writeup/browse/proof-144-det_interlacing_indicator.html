lemma det_interlacing_indicator

What it saysFor k \in \mathbb{N} and weakly decreasing x, y : Fin k \to \mathbb{R} (\mathit{hx}, \mathit{hy}): the determinant of the k\times k matrix whose (b, c) entry is 1 if y(c) < x(b) and 0 otherwise equals 1 if y(b) < x(b) for every b and x(c) \le y(b) whenever c = b + 1 (x_{1} > y_{1} \ge x_{2} > y_{2} \ge \cdots \ge x_k > y_k, interlacing), and 0 otherwise.
The argument in briefInduction on k. If y(0) < x(b+1) for some b, rows 0 and b + 1 are both all ones, so the determinant and the indicator (x(1) \le y(0) fails) vanish. Otherwise only the first entry of column 0 can be 1, and expanding along column 0 reduces to the tails.
