lemma Data.roundUp_mem_Icc

What it saysFor parameters P, admissible data D over P (explicit), reals F and l, and an instance HasLogLower(D)(F, l) (\exp (l) \le F, so F > 0): F \le roundUp(D, F) \le F + N_1(D).
The argument in briefroundUp(D, F) = N_1(D)\cdot \lceil F/N_1(D)\rceil _+ lies between F and F + N_1(D) because F/N_1(D) \le \lceil F/N_1(D)\rceil _+ < F/N_1(D) + 1 for F \ge 0 (F > 0 by the lower bound).
