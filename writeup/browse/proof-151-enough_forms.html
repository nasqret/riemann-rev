lemma Data.enough_forms

What it saysTheorem B (enough forms). For parameters P (N_{0} = P.N_{0}, d = P.d) and admissible data D for P (Lean's Data P): 0 < \dim \operatorname{Column}(D), 0 < \dim \operatorname{rows}(D), and there is a finite set t \subseteq \mathsf{G}_D with \#t\cdot\dim \operatorname{Column}(D) \le 5\cdot\dim \operatorname{rows}(D)\cdot\log(1 + b_D^{2}) and (1 - 4/b_D^{2})\cdot\dim \operatorname{rows}(D) \le \dim(\sum_{s\in t} range P_{D,s}) (the sum of the images, a subspace of the rows).
