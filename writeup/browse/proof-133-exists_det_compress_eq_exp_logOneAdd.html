lemma exists_det_compress_eq_exp_logOneAdd

What it saysLet n be a finite index type, P , Q , X , Y complex n \times n matrices and \delta , c \in \mathbb{R}. Assume that P and Q are orthogonal projections ( P^{2} = P = P^{H} , Q^{2} = Q = Q^{H} ) (hP, hQ), \delta \le 1 / 2 (hδ), \lVert X \rVert \le \delta (hX), \operatorname{tr} ( [ P , Q ] \cdot Y ) = 0 (h0), \lVert [ P , X ] - Y \rVert \le \delta \cdot c (h1), \lVert Y \rVert \le c (hY) and \lVert Q - P \rVert \le c (hD), where \lVert \cdot \rVert is the Frobenius norm and [ A , B ] = AB - BA. Then there is r \in \mathbb{C} with \det ( 1 + PX ) = \exp ( \operatorname{tr} ( Q \cdot \operatorname{lg} ( X ) ) - \tfrac{1}{4} \cdot \operatorname{tr} ( Y^{2} ) + r ) and | r | \le 100 \cdot \delta \cdot c^{2}, where \operatorname{lg} = logOneAdd.
The argument in briefWrite \log \det ( 1 + PX ) = \int_{0}^{1} \operatorname{tr} ( ( 1 + sPX )^{- 1} PX ) \,\mathrm{d}s and \operatorname{tr} ( Q \operatorname{lg} X ) = \int_{0}^{1} \operatorname{tr} ( Q ( 1 + sX )^{- 1} X ) \,\mathrm{d}s; the difference plus \int_{0}^{1} s \cdot \tfrac{1}{2} \operatorname{tr} ( Y^{2} ) \,\mathrm{d}s = \tfrac{1}{4} \operatorname{tr} ( Y^{2} ) is r. Its integrand is rewritten, using h0 and the inverse identities, as a combination of four traces of products of small factors, each bounded by products of norms; the total is at most 100 \delta c^{2}.
