lemma exists_principalMinor_eq_exp

What it saysLet n be a finite index type, \varepsilon : n \to \{ \pm 1 \} signs, h \in \mathbb{R}, l : n \to \mathbb{Z} a doubled Harish-Chandra parameter for \varepsilon of gap h (hg), and g \in U ( \varepsilon ); put X = g - 1 and assume \lVert X \rVert < 1 / 1000 (Frobenius norm). Then there is a complex n \times n matrix y with \psi_{l} ( g ) = FJ_{l} ( 1 , y ) ( FJ = flenstedJensen) such that for every decidable predicate p on n with l_{i} < l_{j} whenever p ( i ) and \neg p ( j ) (p picks a set of lowest entries of l), and every k \in K_{\varepsilon} = maxCompactU( \varepsilon ) (read as a matrix), there is r \in \mathbb{C} with \Delta_{p} ( k^{H} yk ) = \exp ( \operatorname{tr} ( P_{p} \cdot \operatorname{lg} ( X ) ) + \lVert [ P_{p} , X ] \rVert^{2} / 4 + r ) and | r | \le 2 \cdot 10^{5} \cdot \lVert X \rVert \cdot ( \lVert [ P_{p} , X ] \rVert^{2} + \lVert [ P_{p} , k ] \rVert^{2} ), where \Delta_{p} = principalMinor( \cdot , p ) , P_{p} = coordProj( p ) and \operatorname{lg} = logOneAdd.
The argument in briefFactor g's lower and upper parts out: y ( c ) = ( 1 - u ) g ( 1 - r ( c ) ) with r ( c ) the part of X strictly below the diagonal for the order c within the sign blocks and u = r ( - l ). Flensted-Jensen's shift invariance gives \psi_{l} ( g ) = FJ_{l} ( 1 , y ( l ) ); triangularity gives \Delta_{q} ( y ( l ) ) = \Delta_{q} ( g ) for upper sets q of l (step 8). The theorem is about a lower set p (lowest entries of l): step 8 is applied to its complement \neg p (an upper set, step 20) and to the full index set (\det y ( l ) = \det g, step 21). Three applications of the compression lemma (for 1 - P on g - 1, for 1 - P on y ( l ) - 1, and for Q = kPk^{H} against P on y ( l ) - 1), compared through these, give the expansion of \Delta_{p} ( k^{H} y ( l ) k ); the error terms are bounded by norm arithmetic.
