lemma exists_common_coset_reps

What it saysLet F be a semilocal field with compact open subring O, and b, n finite index types. There are a linear functional \ell on the complex functions on \mathrm{GL}_b(F) and a choice of representatives r_q \in \mathrm{GL}_b(F) of the cosets q \in \mathrm{GL}_b(F)/\mathrm{GL}_b(O) such that: (1) for every finite set t of cosets and every function f with f(r_q) = 0 for all q \notin t, \ell(f) = \sum_{q\in t} f(r_q); and (2) for every n \times b matrix y over F having a left inverse, there is exactly one coset q with y\cdot r_q primitive (IsPrimitiveMatrix O: entries in O and a left inverse with entries in O), and exactly one coset q with y\cdot r_q^{-1} primitive.
The argument in briefChoose representatives adjusted by \mathrm{GL}_b(O) so that inverse transposes stay representatives (Smith normal form), and extend the finite-sum functional from finitely supported functions to all functions.

    For each coset q choose k(q) \in \mathrm{GL}_b(O) with (\overline{q}^{-1})^{-T} = k^{-T}\cdot \overline{q}\cdot k for the chosen element \overline{q} of q (exists_invTransposeGL_inv_eq, from the Smith normal form of the valuation pair; Skolem) and put r_q = \overline{q}\cdot k(q); extend the functional "sum of the values", defined on finitely supported functions, to a linear functional \ell on all functions (a linear map out of a subspace extends). Property (1) is the extension property for the finitely supported function that agrees with f on t (Finsupp.onFinset). Property (2): a left-invertible y has some u \in \mathrm{GL}_b(F) with y\cdot u primitive (IsValuationPair.exists_isPrimitiveMatrix_mul); two such differ by an element of \mathrm{GL}_b(O) (IsPrimitiveMatrix.mul_iff, isPrimitiveMatrix_iff_mem_intGL), so exactly one coset works; the same for r_q^{-1}, inverse transposes of elements of \mathrm{GL}_b(O) lying in \mathrm{GL}_b(O) (invTransposeGL_mem_intGL).
