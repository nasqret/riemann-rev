defRiemannZetaZerosOnLine

Statement 1 of the note · unit 153 · Statements.lean, lines 3–4

The proposition RiemannZetaZerosOnLine (the Riemann hypothesis): for every complex number s, if \zeta(s) = 0, if s is not of the form -2(n + 1) for any natural number n (that is, s is none of the trivial zeros -2, -4, -6, \ldots), and if s \ne 1, then \operatorname{Re} s = 1/2. Here \zeta is Mathlib's riemannZeta, the meromorphic continuation of \sum_{n\ge 1} n^{-s} to \mathbb{C}; Mathlib defines it at every complex number, also at the pole s = 1, where it takes a conventional finite value.

defDirichletLNonvanishingRightOfHalf

Statement 2 of the note · unit 153 · Statements.lean, lines 6–8

The proposition DirichletLNonvanishingRightOfHalf (the generalised Riemann hypothesis for Dirichlet L-functions, in half-plane form): for every natural number N with N \ne 0 (Lean's instance argument NeZero N), every Dirichlet character \chi modulo N with complex values, and every complex number s with 1/2 < \operatorname{Re} s, if \chi is not the principal character modulo N or s \ne 1, then L(s, \chi) \ne 0. Here L(s, \chi) is Mathlib's DirichletCharacter.LFunction χ s, the meromorphic continuation of \sum_{n\ge 1} \chi(n) n^{-s} (for the principal character it has a pole at s = 1, where Mathlib assigns a conventional value); a Dirichlet character modulo N is Mathlib's DirichletCharacter ℂ N, a multiplicative map \mathbb{Z}/N \to \mathbb{C} that vanishes off the units, and 1 is the principal character modulo N (1 on the units, 0 elsewhere).

defDirichletLZerosOnLine

Statement 3 of the note · unit 153 · Statements.lean, lines 10–12

The proposition DirichletLZerosOnLine (the generalised Riemann hypothesis for Dirichlet L-functions, critical-strip form): for every natural number N with N \ne 0 (instance NeZero N), every Dirichlet character \chi modulo N with complex values, and every complex number s with 0 < \operatorname{Re} s and \operatorname{Re} s < 1 and L(s, \chi) = 0, one has \operatorname{Re} s = 1/2. Here L(s, \chi) is Mathlib's DirichletCharacter.LFunction χ s, the meromorphic continuation of \sum_{n\ge 1} \chi(n) n^{-s} (for the principal character it has a pole at s = 1, where Mathlib assigns a conventional value); a Dirichlet character modulo N is Mathlib's DirichletCharacter ℂ N, a multiplicative map \mathbb{Z}/N \to \mathbb{C} that vanishes off the units, and 1 is the principal character modulo N (1 on the units, 0 elsewhere).

defPrimitiveDirichletLZerosOnLine

Statement 4 of the note · unit 153 · Statements.lean, lines 14–16

The proposition PrimitiveDirichletLZerosOnLine (the same for primitive characters only): for every natural number N with N \ne 0 (instance NeZero N) and every Dirichlet character \chi modulo N with complex values that is primitive (Mathlib's DirichletCharacter.IsPrimitive: the conductor of \chi equals N), and for every complex number s with 0 < \operatorname{Re} s and \operatorname{Re} s < 1 and L(s, \chi) = 0, one has \operatorname{Re} s = 1/2. Here L(s, \chi) is Mathlib's DirichletCharacter.LFunction χ s, the meromorphic continuation of \sum_{n\ge 1} \chi(n) n^{-s} (for the principal character it has a pole at s = 1, where Mathlib assigns a conventional value); a Dirichlet character modulo N is Mathlib's DirichletCharacter ℂ N, a multiplicative map \mathbb{Z}/N \to \mathbb{C} that vanishes off the units, and 1 is the principal character modulo N (1 on the units, 0 elsewhere).
