What it saysLet S, S' be sides with a pairing h, \varepsilon : letters \to \mathbb{Z}^\times, cut a predicate on letters, s, \beta : letters \to \mathbb{N} and \eta, V, W, X, \kappa, b, n, J, s_{0}, G, e \in \mathbb{N} (d = differentExp(k), e_k the ramification index of the chart, \sigma the letter Frobenius) such that: (hW) V + 4\eta \le W; (hU) opposing windows of width V: for every letter j the jumps of S lie in [-\eta, \eta] \cup (-\varepsilon(j))\cdot[\beta(j), \beta(j) + V] and those of S' in [-\eta, \eta] \cup \varepsilon(j)\cdot[\beta(j), \beta(j) + V]; (hη) \eta \ge 1; (hX) (J + 1 + d + \lfloor \log_p(2b)\rfloor)\cdot n + d\cdot G \le X; (hκ) 12(J + 1)\cdot X < \kappa; (hδ) e_k\cdot2b \le p^{J+1}\cdot X; (h₈) 8e_k \le p^{J+1}; (hs) W \le n, W \le G and \beta(j) + s(j) + W \le 2b for every letter j; (hy) G \le (p - 1)\cdot n; (hK) at every letter j with \operatorname{cut}(j): either s(j) = 0 and \beta(\sigma^{t}(j)) + W \le G for 1 \le t \le J, or s(j) < \beta(j), the chart is unramified, p \ge 5 and s_{0} \le \kappa + s(j); (hz) if p \ge 5, then \beta(j) + W \le (p - 3)\cdot s_{0} for every letter j; with s(i) + W \le p\cdot n for every letter i (hd), 51\kappa \le e (he), every letter i having a cut \sigma^{-l}(i) with 0 < l \le 2J + 1 (hL), and (H): for every letter i and l such that \sigma^{-l}(i) is a cut and \sigma^{-a}(i) is not for 0 < a < l, there is t such that either for all a < l the sign \varepsilon(\sigma^{-a}i) equals \varepsilon(\sigma^{-t}i) or \beta(\sigma^{-a}i) + V \le \eta; or the chart is unramified, p \ge 5, s(\sigma^{-l}i) = 0, t + J + 1 = l, (s(i) = 0 or t = 0), s_{0} + G\cdot\sum_{a\le J} p^{a} < \beta(\sigma^{-t}i), and for all a < l with a \ne t: (the signs differ or \beta(\sigma^{-a}i) + V \le \eta) and (t < a \implies \beta(\sigma^{-a}i) + W \le G). Then ScaledCupBounds(h, e, c, c') for all c \in C, c' \in C'.
