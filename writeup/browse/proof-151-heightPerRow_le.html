lemma Data.heightPerRow_le

What it saysChoice of the level prime. For parameters P (N_{0} = P.N_{0}, d = P.d) and admissible data D for P (Lean's Data P): h_{0}(D) \le h_{\mathrm{main}}(D) - m_D\cdot\operatorname{rem}(D) + \mathcal{B}(D), where h_{0}(D) = D.heightPerRow = m_D\cdot(\sum_{\tau\in\mathrm{tops}(D)} (\mathrm{jetSize}_D(a_D) - \operatorname{Ask}(D, a_D, \tau)) + k_D\cdot\mathsf{U}(D)) - \#\operatorname{tops}(D)\cdot a_D\cdot\log N_D (N_D the level prime of D) and \mathcal{B}(D) = f_D\cdot a_D\cdot(\log b_D)^{3}.
The argument in briefStirling bounds the jet size; the level prime N is chosen with \log N \ge \lambda, which cancels the main term m\cdot a(\overline{w} + G) of the excesses; the rest is within the budget.
