What it saysFor a side S and a finite set I of steps (a, n) \in \mathbb{N} \times \mathbb{Z}: there is an additive map A on kisinLoc(extLattice(S)) of cost \sum_{(a,n)\in I} \operatorname{cost}(a, n) (Reaches(S, \sum cost, A)) such that for every letter i, exponent function c_{0}, x \in deepElements(S, i, c_{0}) and exponent function c_{1}: if I contains every (a, n) with c_{0}(a, u) \le n < c_{1}(a, u) for some u \in U_{\sigma^{-a}(i)}, then A(x) \in deepElements(S, i, c_{1}).
The argument in briefInduction on I by its largest n: each step (a, n) is the operator B = p^{\mathrm{cost}} + \sum_l coordRetract(\upsilon z\tau^{-1}(t_l - 1)) of exists_reaches_depth_succ, which costs \operatorname{cost}(a, n) and raises the depth at (a, u) from n to n + 1; compose.
