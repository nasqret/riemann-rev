    For a, u \in U_{\sigma^{-a}(i)} and \mu of type u: g\cdot V - V = valueAt(L, a, \mu, g\cdot x - x) \in hodgeFil(hi(a, u)) for every g \in \Gamma' (valueAt_smul_sub, H), V = valueAt(L, a, \mu, x); hence V - c \in hodgeFil(hi(a, u)) for some c \in \overline{Q}_p (BdR.exists_sub_mem_of_smul_sub_mem). Let m = improvedExponent(lo, hi)(a, u) = \min(hi(a, u), hi(a, u) if lo(a, u) > 0 else 0). As m \le hi(a, u), V - c \in hodgeFil(m), so it suffices that c \in hodgeFil(m). If m \le 0 this holds, c \in \overline{Q}_p \subseteq B_{\mathrm{dR}}^{+} = hodgeFil(0) \subseteq hodgeFil(m). If m > 0, then lo(a, u) > 0 and hi(a, u) > 0 (a case split: lo(a, u) > 0 alone does not make \min(lo, hi) positive), so c = V - (V - c) \in hodgeFil(\min(lo(a, u), hi(a, u))) (V \in hodgeFil(lo(a, u)) by hx) has a positive index, and c = 0 (qpBar_mem_hodgeFil_iff). (So: hi \le lo and lo > 0 give the old bound hi; hi > lo > 0 make c vanish; lo \le 0 gives \min(hi, 0).)
